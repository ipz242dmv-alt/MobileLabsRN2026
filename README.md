# MobileLabsRN2026

Лабораторні роботи з дисципліни **«Розробка мобільних додатків»** (React Native + Expo).

**Виконала:** Дзядзін М. В., група ІПЗ-24-2
**Викладач:** Нерода С. І.

| № | Тема | Папка |
|---|---|---|
| 1 | Використання Expo для створення найпростішого додатку React Native. Знайомство з основними компонентами | [lab1](lab1/) |
| 2 | Віртуалізація списків та побудова навігації | [lab2](lab2/) |
| 3 | Expo Router: кастомізація навігаційних компонентів, нативні модальні вікна та віртуалізація списків | [lab3](lab3/) |

Кожна лабораторна — окремий Expo-проєкт (Expo SDK 57, Expo Router; для запуску потрібен Expo Go із підтримкою SDK 57). Запуск:

```bash
cd lab1   # або lab2 / lab3
npm install
npx expo start
```

Опис, скріншоти та висновки — у `README.md` кожної папки.
